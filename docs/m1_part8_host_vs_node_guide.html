Phần 8 — Đối chiếu host ↔ node và chốt M1

So đáp ứng bậc thang trên node (QEMU) với mô phỏng host, tổng hợp bằng chứng của ba tiêu chí M1 và các việc còn mở.

Cùng mã lõi, cùng tham số, không nhiễu: đáp ứng bậc thang của node (QEMU) khớp host với sai lệch lớn nhất 1·10⁻⁶ rad (chỉ là sai số làm tròn khi in 1 µrad ra UART), count lệch 0, overshoot 0,209 % ở cả hai nơi. 1. Mục tiêu và cách làm

Mục tiêu (plan M1 Phần 8): chứng minh lõi điều khiển không phụ thuộc môi trường — cùng mã chạy trên x86 (host) và Cortex-M3 (QEMU, float mềm, -Os) cho đáp ứng giống nhau — rồi chốt M1.

  1. Chạy node (CONTROL_TEST_STEP, -icount shift=0), lấy CSV UART (C,tick,count,pos_urad,vel_mrad_s,volt_mV).
  2. Chạy sim_closed_loop step trên host với cấu hình mặc định (không nhiễu, α = 0,5) lấy CSV tham chiếu.
  3. tools/compare_host_node.py: so 1000 tick đầu (bước 1 rad đầu tiên) theo vị trí, tốc độ, điện áp, count; tính lại overshoot/settling/sai số xác lập từ dữ liệu của node.
  4. Tổng hợp tài liệu từng phần và cập nhật trạng thái.

2. Kiến thức — Vì sao host và node phải khớp

  • Tính tất định: cùng mã + cùng trạng thái đầu + cùng chuỗi đầu vào ⇒ cùng đầu ra. Ở đây mô hình plant, encoder (PRNG xorshift có seed; noise = 0) và cascade đều tất định và không có thời gian thật chen vào (dt = 1 ms là tham số).
  • Khác biệt duy nhất được phép: số học dấu phẩy động. Host dùng SSE float; node dùng thư viện float mềm của GCC. Cả hai theo IEEE 754 nên phép + - * / cho kết quả giống từng bit; chênh lệch (nếu có) đến từ trình biên dịch (thứ tự biểu thức, hợp nhất FMA) và hàm toán (cosf/logf, chỉ dùng khi bật nhiễu). Vì vòng kín ổn định, sai lệch nhỏ không bị khuếch đại.
  • Ý nghĩa của việc khớp: thuật toán đã được kiểm chứng ở host (nhanh, nhiều kịch bản) có thể tin cậy khi chạy trên node; ngược lại nếu lệch thì lỗi nằm ở adapter (thứ tự gọi, đơn vị, vùng MPU), không phải ở lõi.
  • Dung sai chọn: 1·10⁻³ rad (≈ 0,65 count) cho vị trí — đủ chặt để phát hiện sai thứ tự/đơn vị, đủ rộng cho sai khác float. Giá trị thực đo được nhỏ hơn dung sai ba bậc độ lớn.
Căn thẳng hàng tick: dòng C,k,… của node in trạng thái sau bước plant thứ k; dòng thứ k (0-based) của CSV host cũng là trạng thái sau bước k. Trong cả hai, vòng điều khiển đọc encoder từ vị trí trước khi bước plant, nên cùng thứ tự.

3. Công cụ đối chiếu

def main(argv=None):
    ap = argparse.ArgumentParser()
    ap.add_argument("node")
    ap.add_argument("host")
    ap.add_argument("--ticks", type=int, default=1000)
    ap.add_argument("--tol-rad", type=float, default=1e-3)
    ap.add_argument("--out")
    a = ap.parse_args(argv)

    node = load_node(a.node)
    host = load_host(a.host)
    missing = [k for k in range(a.ticks) if k not in node]
    if missing:
        print("FAIL: node CSV is missing %d of the first %d ticks (first missing: %d)" % (len(missing), a.ticks, missing[0]))
        return 1

    dpos = [abs(node[k][1] - host[k]["pos"]) for k in range(a.ticks)]
    dvel = [abs(node[k][2] - host[k]["vel"]) for k in range(a.ticks)]
    dv = [abs(node[k][3] - host[k]["v"]) for k in range(a.ticks)]
    dcount = [abs(node[k][0] - int(host[k]["count"])) for k in range(a.ticks)]
    worst = max(range(a.ticks), key=lambda k: dpos[k])

    nd = {"ref": [1.0] * a.ticks, "pos": [node[k][1] for k in range(a.ticks)]}
    nm = step_metrics(nd)
    hd = {"ref": [1.0] * a.ticks, "pos": [host[k]["pos"] for k in range(a.ticks)]}
    hm = step_metrics(hd)

    ok = (max(dpos) <= a.tol_rad and nm["overshoot_pct"] < 10.0 and nm["settling_ticks"] <= 200
          and nm["ss_error_counts"] <= 1.0)
    lines = [
        "M1 Part 8: host vs node step response (SIL; node = QEMU mps2-an385, virtual time, 1 tick = 1 ms model)",
        "compared ticks 0..%d" % (a.ticks - 1),
        "max |dpos| = %.3e rad at tick %d (tolerance %.1e rad)" % (max(dpos), worst, a.tol_rad),
        "max |dvel| = %.3e rad/s, max |dV| = %.3e V, max |dcount| = %d" % (max(dvel), max(dv), max(dcount)),
        "host: overshoot=%.3f%% settling=%d ticks ss_error=%.3f counts" % (hm["overshoot_pct"], hm["settling_ticks"], hm["ss_error_counts"]),
        "node: overshoot=%.3f%% settling=%d ticks ss_error=%.3f counts" % (nm["overshoot_pct"], nm["settling_ticks"], nm["ss_error_counts"]),
        "limits: overshoot < 10%%, settling <= 200 ticks, ss_error <= 1 count -> %s" % ("PASS" if ok else "FAIL"),
    ]
    text = "\n".join(lines)
    print(text)
    if a.out:
        Path(a.out).write_text(text + "\n")
    return 0 if ok else 1

Các chênh lệch bằng đúng bước làm tròn khi in số nguyên ra UART (µrad, mrad/s, mV), nghĩa là bên trong hai bên khớp tới giới hạn độ phân giải của log. Tôi không nói "bằng từng bit": log không đủ độ phân giải để khẳng định điều đó.
